# Бот-уведомление об изменении баланса битомата (Винница, ул. Зодчих, 2)

Проверяет страницу раз в 5 минут и пишет в Telegram, когда сумма
"Доступная наличность сейчас" изменилась (плюс на сколько).

## Шаг 1. Создать Telegram-бота
1. В Telegram напиши **@BotFather** → `/newbot` → следуй подсказкам.
2. Получишь токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
3. Напиши своему новому боту любое сообщение (просто "привет"), иначе он не
   сможет писать тебе первым.
4. Открой в браузере:
   `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
   Найди в ответе `"chat":{"id": ЧИСЛО, ...}` — это твой `CHAT_ID`.

## Шаг 2. Создать репозиторий на GitHub
1. Зайди на github.com, создай новый репозиторий (можно приватный).
2. Загрузи туда файлы из этого набора: `check_atm.py`,
   `.github/workflows/check.yml` (сохраняя структуру папок!).

## Шаг 3. Добавить секреты
В репозитории: **Settings → Secrets and variables → Actions → New repository secret**
- `BOT_TOKEN` — токен бота из шага 1
- `CHAT_ID` — твой chat_id из шага 1

## Шаг 4. Разрешить боту коммитить
**Settings → Actions → General → Workflow permissions** →
выбери **"Read and write permissions"** → Save.
(Это нужно, чтобы скрипт мог сохранять последнее известное значение в
файл `last_value.txt` между запусками — иначе он не будет помнить,
что было "до".)

## Шаг 5. Проверить вручную
Вкладка **Actions** → выбери workflow "Check ATM balance" →
**Run workflow** — запустится сразу, не дожидаясь расписания.
Первый запуск ничего не пришлёт (это нормально — он просто
запоминает стартовое значение), присылать будет со следующего
запуска, если сумма изменится.

## Важно
- Расписание `*/5 * * * *` = раз в 5 минут. Это минимум, который
  надёжно даёт бесплатный GitHub Actions (раз в 1 минуту бесплатно
  нигде стабильно не работает — нужен свой постоянно включённый
  сервер).
- Если скрипт упадёт с ошибкой "Не нашёл сумму на странице" — значит
  сайт стал отдавать это число через JavaScript, а не в исходном HTML,
  и придётся переделать на headless-браузер (Playwright). Смотри
  логи в Actions, если что-то пойдёт не так — пришли их сюда, разберёмся.
